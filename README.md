# Online Doctor Consultation System

A web-based application for booking doctor appointments and managing consultations.

## Features
- User authentication
- Doctor appointment booking
- Backend API integration
- Route and middleware management

## Technologies Used
- Node.js
- Express.js
- JavaScript
- MongoDB

## Project Structure
- controllers/
- models/
- routes/
- middleware/

## How to Run
1. Clone the repository
2. Run npm install
3. Run npm start
